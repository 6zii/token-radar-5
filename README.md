Token launch radar — radar-5 model, evidence for every number. A Node 22 program that reads a sealed DefiLlama snapshot, refits the size curve on the snapshot's own live peers in the browser, ranks every clean pre-token protocol by implied value, and writes a 198-row board with 5 nearest traded comparables per row, a derivation table, 8-step farm plans, and a what-if panel — so every number on the board can be checked against its own evidence.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
